# 套圈夜市

手机浏览器里的限时套圈小游戏。竖屏按住上拖瞄准，松手把圈子投到庙会摊位上，圈影套住木桩就得分。没有账号、支付或服务器。

## 本地运行

```bash
npm install
npm run dev
```

开发地址：[http://127.0.0.1:43123](http://127.0.0.1:43123)

```bash
npm test
npm run test:e2e
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再把静态文件输出到 `dist/`。预览地址是 [http://127.0.0.1:43124](http://127.0.0.1:43124)。

## 怎么玩

1. 按住屏幕向上拖。拖得越远，飞得越远。
2. 左右移动，让地上的圈影套住木桩。
3. 松开手指投出。套中得分，连续套中最多 ×3。
4. 45 秒结束后可以再来一局。

鼠标在桌面上使用同一套拖放。系统开启“减少动态效果”时，会去掉摇晃、粒子和灯笼摆动，投掷仍会沿同一条弧线落下，只是更快。

## 部署

这是纯静态页面，把 `dist/` 目录交给任意静态文件托管即可。资源使用相对路径。不需要环境变量、数据库或后端。

手机上的音效需要安全上下文（HTTPS，或本机的 localhost）。未配置托管时，只能在本地预览，没有公网地址。
